# ResumeAI 🚀

AI-powered resume analysis and improvement platform that helps users understand their resume quality, identify skill gaps, and improve their resume for ATS compatibility.

## ✨ Features

- 📄 Resume upload and analysis
- 📊 Overall resume scoring
- 🤖 ATS compatibility analysis
- 🛠️ Technical skill detection
- 💡 Resume improvement suggestions
- 📝 Job-description based analysis
- 📈 Skill and keyword analysis
- 🌐 React-based dashboard
